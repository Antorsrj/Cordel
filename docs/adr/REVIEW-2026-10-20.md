## Cross-ADR findings

1. **The test VM and source are at different stages.** The VM has ADR-002 migrations `1,2` and the admin-grant binary. ADR-003 migration `3`, routes, and policy consumers are not deployed. A source or CI pass does not verify live moderation.
2. **Media admission is still provisional.** Phase 0 joins with a separately supplied LiveKit token. The intended Axum-issued, room-scoped admission from Server 005 is not integrated, and Server 006 still needs old-token denial proof.
3. **The Linux client is build-verified, not interaction-verified.** CI does not exercise the OS picker, microphone permission, real screen-share consent lifecycle, credential store, or Journal behavior in a desktop session.
4. **Recovery and binary release remain gated.** No off-host database restore has been verified for the populated test database. Client 106 still needs packaged Slint attribution and a complete dependency/native-library notice audit.
5. **The first product test has not started.** All 16 mandatory ADRs need completion evidence in [STATUS.md](STATUS.md), including acceptance of Proposed 006, 007, 009, and 011. The [percentage overview](../README.md) is only a planning estimate.
