## Documentation review — 2026-10-17

The 20 ADRs, [workstream map](WORKSTREAMS.md), [v1 contract](../contracts/v1.md), [Journal specification](../ux/journal.md), project vision, deployment architecture, agent instructions, and parking lot were reviewed together. The handoff now distinguishes client-side active-speaker events from server presence, carries a presence stream ID across restarts, includes older-history pagination, binds temporary image uploads to author/channel, and defines pre-login browser CSRF bootstrap. Official [LiveKit token guidance](https://docs.livekit.io/frontends/reference/tokens-grants/) confirms self-hosted removal does not revoke old tokens; ADR-006 therefore requires strict old-token denial evidence rather than room isolation alone. [Slint's window/global guidance](https://docs.slint.dev/latest/docs/slint/reference/language/globals/) and [texture guidance](https://docs.slint.dev/latest/docs/rust/slint/struct.BorrowedOpenGLTextureBuilder.html) remain Phase 0 feasibility inputs.
